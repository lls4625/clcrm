## ClCrm v1 当前实现

当前为首轮代码基线，尚未执行依赖解析、构建、编译、安装或自动测试，不能视为已经通过运行验收的正式版本。

应用名称为 ClCrm，Bundle ID 为 `vip.ichiki.javalee.clcrm`。代码参考 ClPlan 的 Flutter、ChangeNotifier、SQLite 与 Swift 平台通道结构，采用独立数据库，不访问 ClPlan 的数据。

### 已落入源码的功能

- 待办、客户、我的三个主入口。
- 客户新增/编辑、曾用名、同名提示、多选类别、搜索、省市区筛选和分页。
- 客户下多联系人、主要联系人、重复电话提示、复制电话及确认后系统拨号。
- 多次购买记录；软件、服装、服务补充字段及历史商品名称选择。
- 实际联系录入、补录、明天/3/7/30天后加手动选时、联系与下次任务一起保存。
- 完成任务时录入实际结果、改期历史、取消任务，防止重复完成生成重复联系。
- 普通任务的本地通知、主动授权、到时/提前一天、隐藏内容、有限排程、通知打开客户档案。
- 近1/2/3个月设备本地日历统计预览、客户去重、省级数字与客户名单。
- 无密码Excel导出、空白模板、预览；只新增客户的逐行校验、同名确认及整批事务导入。
- 六组设置、主题、字号、类别维护与排序、联系人目录、权限/存储说明、操作记录、关于与实际安装包版本、开源许可。

### 明确保留占位的功能

完整备份的所属用户识别、默认密码协议及覆盖恢复尚未确定，因此当前没有生成完整备份或导入覆盖的入口。不能把Excel导出当成完整备份。

附件、安全锁、回收站与删除、独立商品管理、复杂组合统计、每日汇总、购买到期自动任务、其他语言、真实支付及评分跳转尚未开放。购买记录当前支持新增及查看，联系记录支持新增及查看；历史修改的关联行为待补充。

Excel暂不支持现有记录更新、清空字段、跨库合并、联系人/购买/联系/任务等关联表写入；可导出这些表并预览，但不会假装已导入。

### 手动准备与运行

工程配置的创建已得到用户单独授权，但没有执行任何构建或测试操作。

请由维护者手动在当前目录安装/解析Flutter依赖，再使用Flutter或打开 `ios/Runner.xcworkspace` 选择设备并运行。iOS工程参考ClPlan的Swift Package Manager集成；需要使用能够处理同类工程的Flutter/Xcode环境。Debug、Release、Profile已沿用ClPlan的开发团队 `3TLP2Z5QX5` 并设置自动签名；实际描述文件与设备授权仍由Xcode在你手动运行时处理。

初始SDK约束参考ClPlan的 Dart `^3.13.2`，iOS工程沿用其 `15.0` 配置作为工程起点；这不是已验证的最低系统承诺。没有复制Generated.xcconfig、插件注册器、ephemeral包、Pods或任何构建产物，这些由你手动操作Flutter工具时产生。

没有添加测试目录、测试目标或独立构建脚本；Xcode工程保留Flutter标准运行阶段。

### 数据与当前实现限制

- SQLite文件为 `clcrm.sqlite3`，schema版本1，启用外键，业务写入使用事务。不会在启动失败时清空数据库。
- 时间点保存为固定6位小数的UTC文本；日期保存为 `YYYY-MM-DD`。目前界面使用设备本地时间，完整业务时区策略待定。
- 客户编号暂使用完整随机UUID保证唯一，展示编号规则后期补充。
- 数量、金额和工时按原文保留，不使用浮点数汇总，也没有默认假设币种。
- 客户列表每页40条；详情各分区及联系人目录最多展示200条；任务页每个时间范围最多展示200条，界面会提示展示限制。
- 通知初始未开启；用户在设置中主动启用并通过系统授权后才排程。当前最多排程60条未来请求，应用启动、回到前台和修改资料后重新协调。没有后台无限续排承诺。
- Excel预览防御性限制：文件10MB、声明解压内容60MB、20张工作表、总10000行、每表100列；不执行公式。导出总计最多10000业务行；客户新增导入单批最多1000行。这些是首轮资源保护边界，并非已经实测的产品容量承诺。
- Excel所有字段使用文本单元格输出，避免手机号和编号前导零丢失。默认导出多表业务资料，但不包含附件、完整设置或完整备份归属信息。
- 新增导入只处理“客户”工作表，内部ID和客户编号须留空，客户名称、省、市必填，其他业务表不能含数据。任何校验错误均阻止整批写入；同名行需逐项确认允许独立新增。
- 不内置真实客户演示数据，只预置软件、服装、服务三种业务类别。
- 原始图标不变，工程图标是去透明背景和尺寸适配的副本。

### 文件入口

- `lib/main.dart`：应用启动、简中资源、主题与字号。
- `lib/core/database.dart`：schema、持久化、查询、事务、导入及操作记录。
- `lib/features/`：客户、表单、待办、统计、数据交换和设置。
- `lib/services/`：Excel文件处理与本地通知。
- `ios/Runner/AppDelegate.swift`：iOS通知、拨号和版本桥接。
